# Instagraim.in static website

This is a backend-free, single-page website. The tools run in the visitor's browser with plain HTML, CSS and JavaScript; there is no build step, database, API key or server code.

## Publish

Upload `index.html`, `robots.txt` and `sitemap.xml` to the root of any static web host, then point `instagraim.in` to that host and enable HTTPS. The canonical URL, social metadata and sitemap are set to `https://instagraim.in/`; update those values if you publish on a different domain.

## Included tools

- Caption draft maker with topic, tone and post-goal choices
- Topic and category based hashtag ideas
- Instagram bio builder with a 150-character counter
- Unicode text styles with copy buttons
- Username brainstorming with copyable suggestions

The hashtag and username tools make local suggestions. They do not check live trends, account availability or Instagram data.
- Username brainstorming with copyable suggestions
